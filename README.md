# 題庫測驗網

一個以 Google Sheet 作為題庫來源的 Quizlet 風格測驗網站，純前端（HTML / CSS / JavaScript），無需伺服器或建置流程，可直接部署到 GitHub Pages。科目、課程、單元的內容由一份「目錄 Google Sheet」維護，未來可擴充到英文、國文、數學、生物、社會等多科目。

## 功能

- **登入保護**：進入網站前需輸入密碼（見下方「登入密碼」說明）
- **首頁單一頁面**列出全部單元（不需要一層層點科目/課程才看得到），並提供：
  - 🔍 搜尋框：即時篩選，支援多關鍵字（例如打「英文 12」同時比對科目/課程/單元名稱）
  - 科目篩選標籤（全部 / 英文 / 國文 …）
  - 每張單元卡片標示所屬「科目 > 課程」，點「開始測驗」直接跳到該單元的測驗設定頁
- **測驗前設定**：可選擇「選擇題」或「拼字測驗」，並選擇題數（10 題為單位，或全部題目）
- **選擇題模式**：四選一，選項每次顯示都會重新隨機排列，作答後立即顯示對錯
- **拼字測驗模式**：看題目打出正確拼字，忽略大小寫與頭尾空白差異，答錯會顯示正確拼法
- 兩種模式測驗結束都會顯示分數與錯題列表，可重新測驗
- **響應式設計**：手機、平板、桌機皆可正常瀏覽

## 登入密碼

目前僅設計給單一使用者登入，預設密碼是 `0709`。

- 密碼**不是**用明文儲存在程式碼中，而是存放 SHA-256 雜湊值（見 [`js/auth.js`](js/auth.js)），登入時會將輸入的密碼算出雜湊值後比對。
- ⚠️ **這只是避免陌生人隨意瀏覽的輕量防護，不是真正的存取控管**：因為整個網站（含雜湊值）都公開在 GitHub 上，懂技術的人仍可能繞過或暴力破解 4 位數密碼。若未來有更嚴謹的權限需求（例如區分老師/學生帳號、後台管理），需要改用有後端驗證的架構。
- 登入成功後會記在瀏覽器的 `localStorage`，之後開啟同一瀏覽器不需要重複登入；要登出可點選首頁右上角的「登出」按鈕。

### 修改密碼

1. 想好新密碼後，算出它的 SHA-256 雜湊值，例如在終端機執行：
   ```bash
   printf '%s' "你的新密碼" | sha256sum
   ```
2. 將結果貼到 [`js/auth.js`](js/auth.js) 裡的 `AUTH_PASSWORD_HASH` 常數。

## 科目／課程／單元 目錄（維護重點）

網站的科目、課程、單元結構，**不是寫在程式碼裡**，而是統一由一份「目錄 Google Sheet」維護：

- 目錄 Sheet ID 設定在 [`js/config.js`](js/config.js) 的 `DIRECTORY_SHEET_ID` 常數
- 目錄 Sheet 的欄位（依**順序**讀取，不是依標題文字，所以就算標題列被改動也不影響）：

  | 欄位順序 | 說明 |
  |---|---|
  | 1 | 科目名稱，例如「英文」「國文」「數學」「生物」「社會」 |
  | 2 | 課程名稱，例如「Level 1」 |
  | 3 | 單元名稱，例如「Unit 01」 |
  | 4 | 該單元題庫的 Google Sheet ID（該題庫網址中 `/d/` 與 `/edit` 之間那段） |
  | 5 | 啟用：填「是」才會顯示在網站上，其他（含空白）都視為未啟用 |

- **新增科目、課程、單元，都只要在這份目錄 Sheet 裡新增一列即可，不需要改程式碼、也不需要重新部署。**
- 網站只會顯示至少有一個「啟用」單元的科目／課程，避免出現空白頁面。
- 單元在網站上出現的順序，就是目錄 Sheet 由上到下的列順序。
- 目錄 Sheet 跟每份單元題庫一樣，都需要設定為「知道連結的任何人皆可查看」。

## 單元題庫的資料格式

每個單元對應一個 Google Sheet，需符合以下欄位（見任一份現有題庫）：

| 單元 | 題號 | 題目 | 正確答案 | 第一個其他答案 | 第二個其他答案 | 第三個其他答案 |
|---|---|---|---|---|---|---|

- `題目` 中的空格請用底線表示，例如 `Judy is _____ hard-working student.`
- 若某題的錯誤選項不足 3 個，可以用 `X` 填入空缺欄位，程式會自動忽略。
- 一樣需要設定為「知道連結的任何人皆可查看」。

## 更新 CSS / JS 後記得升版本號（避免瀏覽器快取舊版）

兩個 HTML 檔（`index.html`、`quiz.html`）裡的 `css/style.css` 及 `js/*.js` 都加了 `?v=5` 這種版本號查詢字串。瀏覽器與 GitHub Pages 的 CDN 會用檔名（含查詢字串）快取檔案，如果修改了 CSS 或 JS 卻沒改版本號，使用者可能會看到舊版內容。

**每次修改 `css/` 或 `js/` 裡的檔案並要推上 GitHub 時，記得把兩個 HTML 檔裡所有 `?v=N` 的數字都往上加一。**

如果使用者回報「怎麼改了都沒變」，通常就是這個快取問題，請他們對頁面按 `Ctrl+Shift+R`（強制重新整理）。

## 本機預覽

這是純靜態網站，用任何簡易 HTTP 伺服器開啟 `index.html` 即可（部分瀏覽器對 `file://` 開啟本地檔案會有限制，建議用本機伺服器）：

```bash
npx serve .
```

或使用 Python：

```bash
python -m http.server 8000
```

然後開啟 http://localhost:8000

## 部署到 GitHub Pages

1. 將此資料夾推送到 GitHub 上的一個 repository
2. 到 repository 的 **Settings → Pages**
3. Source 選擇 `Deploy from a branch`，Branch 選擇 `main`（或 `master`）、資料夾選擇 `/ (root)`
4. 儲存後，GitHub 會提供一個 `https://<你的帳號>.github.io/<repo名稱>/` 網址

## 專案結構

```
.
├── index.html          # 首頁：全部單元（搜尋 + 科目篩選標籤）
├── quiz.html             # 測驗設定 + 測驗本身（?subject=...&course=...&unit=單元名稱）
├── css/style.css         # 樣式（含登入畫面、搜尋/篩選標籤、響應式設計）
└── js/
    ├── auth.js          # 登入保護（密碼雜湊比對、localStorage 記錄）
    ├── config.js        # 目錄 Google Sheet 的 ID 設定
    ├── directory.js     # 讀取目錄 Sheet，組出科目/課程/單元結構
    ├── sheet.js         # 抓取並解析單元題庫 CSV 資料、共用工具函式
    ├── home.js          # 首頁邏輯（扁平單元清單、搜尋、科目篩選）
    ├── testmode.js      # 選擇題測驗模式
    ├── spellingmode.js  # 拼字測驗模式
    └── quiz.js          # 測驗頁面路由（含測驗前設定畫面：題型、題數）
```
