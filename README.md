# 題庫測驗網

一個以 Google Sheet 作為題庫來源的 Quizlet 風格測驗網站，純前端（HTML / CSS / JavaScript），無需伺服器或建置流程，可直接部署到 GitHub Pages。科目、課程、單元的內容由一份「目錄 Google Sheet」維護，未來可擴充到英文、國文、數學、生物、社會等多科目。

## 功能

- **登入保護**：進入網站前需輸入密碼（見下方「登入密碼」說明）
- **首頁單一頁面**列出全部單元（不需要一層層點科目/課程才看得到），並提供：
  - 🔍 搜尋框：即時篩選，支援多關鍵字（例如打「英文 12」同時比對科目/課程/單元名稱）
  - 科目篩選標籤（全部 / 英文 / 國文 …）
  - 每張單元卡片標示所屬「科目 > 課程」，點「開始測驗」直接跳到該單元的測驗設定頁
- **英文（目前 Level 1、Level 2，各 Unit 01～40）測驗前設定**分兩層：
  - **測驗類別**：A. 中選英（給中文選英文單字）／B. 例句選擇題（英文例句填空）
  - 選 A 才會再多一層**作答方式**：選擇題／拼字題；B 固定只有選擇題
  - 題數依當下選的類別即時更新（A 每單元 25 個單字；B 依單元約 58～70 句例句），可選 10 題為單位或全部
- **其他科目（依目錄 Sheet 維護）** 沿用原本的「選擇題／拼字測驗」二選一設定
- **選擇題模式**：四選一，選項每次顯示都會重新隨機排列，作答後立即顯示對錯
- **拼字題模式**：看題目打出正確拼字，忽略大小寫與頭尾空白差異，答錯會顯示正確拼法
- 測驗結束都會顯示分數與錯題列表，可重新測驗，並自動把成績記錄到「測驗紀錄」Google Sheet（見下方說明）
- **📕 我的錯題**：英文測驗答錯的題目會存起來，登入後可以在首頁點「我的錯題」，依單元/題型重新練習自己答錯過的題目（見下方「錯題本」說明）
- **響應式設計**：手機、平板、桌機皆可正常瀏覽

## 登入身份與密碼

網站目前有 4 個帳號，登入時先選身份、再輸入該身份的密碼：

| 姓名 | 角色 | 密碼 |
|---|---|---|
| Mason | 學生 | `0709` |
| Emily | 學生 | `0221` |
| Jay | 老師 | `0927` |
| Jane | 老師 | `0131` |

- **學生**：只能搜尋單元、開始測驗。每次測驗結束會以登入的姓名記錄成績。
- **老師**：跟學生一樣能測驗，首頁右上角會多出：
  - 每個英文 Level 各一組「📖 OO 單字」「📝 OO 例句」：開啟該 Level 單字/例句 Sheet 的編輯畫面（依 `ENGLISH_LEVELS` 自動產生，加新 Level 也會自動多出一組）
  - 「📊 測驗紀錄」：開啟測驗紀錄 Google Sheet
  - 另外，非英文（目錄 Sheet 維護的舊架構）單元卡片上還會有「✏️ 編輯題庫」按鈕，開啟該單元自己的 Google Sheet 編輯畫面
- 帳號、角色、密碼雜湊值都設定在 [`js/auth.js`](js/auth.js) 的 `USERS` 陣列裡。
- 密碼**不是**用明文儲存，而是存放 SHA-256 雜湊值，登入時把輸入的密碼算出雜湊值，跟「選定身份」對應的雜湊值比對，兩者都要吻合才能登入。
- ⚠️ **這只是切換身份/介面用的輕量防護，不是真正的存取控管**：因為整個網站（含所有雜湊值）都公開在 GitHub 上，懂技術的人仍可能繞過或暴力破解 4 位數密碼；學生登入後填的也不是身分驗證，只是選了一個名字再輸入密碼。
- ⚠️ **「編輯題庫」連結真正能不能編輯，是由該 Google Sheet 自己的共用權限決定，跟這個網站的登入無關**：老師模式只是把編輯網址顯示出來方便點擊，如果某個人在 Google 那邊本來就沒有 editor 權限，就算他用老師密碼登入，點進去也只能看不能改。反過來說，只要知道某份 Sheet 的 ID，任何人都可以自己組出 `/edit` 網址去嘗試，所以題庫的真正保護，還是要靠 Google Sheet 的共用設定（例如只給特定帳號編輯權限）。
- 登入成功後身份會記在瀏覽器的 `localStorage`，之後開啟同一瀏覽器不需要重複登入；要登出（或切換身份）可點選首頁右上角的「登出」按鈕。

### 新增使用者 / 修改密碼

1. 想好密碼後，算出它的 SHA-256 雜湊值，例如在終端機執行：
   ```bash
   printf '%s' "新密碼" | sha256sum
   ```
2. 到 [`js/auth.js`](js/auth.js) 的 `USERS` 陣列，新增一筆 `{ name, role, passwordHash }`，或修改現有那筆的 `passwordHash`。`role` 只能是 `'student'` 或 `'admin'`。

## 測驗紀錄（老師檢視學生測驗成效）

學生每次測驗結束，網站會把結果送到一份「測驗紀錄」Google Sheet，記錄下面欄位：

| 學生姓名 | 科目 | 課程 | 單元 | 題型 | 測驗時間 | 總題數 | 答對題數 | 答錯題數 | 正確率 |
|---|---|---|---|---|---|---|---|---|---|

- 測驗時間固定記錄**台灣時間（UTC+8）**，格式為 `2026-08-05 00:30:59`，跟使用者裝置本身的時區設定無關（見 [`js/quizlog.js`](js/quizlog.js) 的 `formatTaiwanTime`）。
- 老師可以直接打開這份 Sheet 查看、排序、篩選；或用老師身份登入網站後，點首頁右上角的「📊 測驗紀錄」快速開啟。

### 運作方式

因為讀取 Google Sheet 可以用公開的 CSV 網址直接抓，但**寫入**沒辦法這樣做，所以測驗紀錄是透過部署在該 Sheet 上的 **Google Apps Script 網頁應用程式**接收資料再寫入。網站呼叫的端點網址設定在 [`js/quizlog.js`](js/quizlog.js) 的 `QUIZ_LOG_ENDPOINT` 常數。

- 若 `QUIZ_LOG_ENDPOINT` 是空字串，代表尚未部署，測驗結束時就不會嘗試記錄，也不會出現任何錯誤或影響學生看到自己的成績。
- 記錄是「盡力而為」：用 `fetch` 背景送出，送出失敗（例如沒有網路）也不會擋住或干擾學生的畫面。

### 部署步驟（只需要做一次）

1. 開啟你的「測驗紀錄」Google Sheet
2. 上方選單「擴充功能」→「Apps Script」
3. 把預設程式碼整個刪掉，貼上 [`apps-script/quiz-log.gs`](apps-script/quiz-log.gs) 的內容
4. 存檔（Ctrl+S）
5. 右上角「部署」→「新增部署作業」
6. 點類型旁邊的齒輪圖示，選「網頁應用程式」
7. 「執行身份」選「我」；「具有存取權的使用者」選「任何人」
8. 按「部署」，第一次會要求授權——會出現「未經驗證的應用程式」警告，這是正常的（因為是你自己寫的程式，Google 還沒幫你的帳號認證這個應用程式），選「進階」→「前往...（不安全）」繼續即可
9. 部署完成後會顯示一組網址（結尾是 `/exec`），把這組網址交給我，我會把它填入 [`js/quizlog.js`](js/quizlog.js) 的 `QUIZ_LOG_ENDPOINT`

⚠️ **這組網址之後會出現在公開的網站原始碼裡**，理論上任何人都可能對著它送假資料進測驗紀錄 Sheet（沒有辦法完全防堵，因為網站沒有真正的後端驗證）。如果之後發現被濫用，可以到 Apps Script「管理部署作業」停用舊的、重新部署一組新網址。

## 英文（Level 1、Level 2…）資料來源

英文不透過目錄 Sheet 維護，而是每個 Level 各自固定用兩份共用 Google Sheet，網站會**自動掃描其中的「單元」欄位**產生 Unit 01～40（見 [`js/englishdata.js`](js/englishdata.js) 的 `ENGLISH_LEVELS` 清單）：

- Sheet ID 設定在 [`js/config.js`](js/config.js)：`ENGLISH_VOCAB_SHEET_ID`/`ENGLISH_SENTENCE_SHEET_ID`（Level 1）、`ENGLISH_LEVEL2_VOCAB_SHEET_ID`/`ENGLISH_LEVEL2_SENTENCE_SHEET_ID`（Level 2）
- **單字清單**欄位順序：`單元, 項次, 目標單字, 精簡中文釋義, 混淆單字1, 混淆單字2, 混淆單字3`（給「中選英」A 模式用，混淆單字直接當選項，不用另外亂數挑）
- **例句清單**欄位順序：`...單元...測驗挖空句, 正確解答, 錯誤選項1, 錯誤選項2, 錯誤選項3`（給「例句選擇題」B 模式用）
- ⚠️ 這兩份都是**依欄位順序**讀取，不是依標題文字（Level 2 單字清單的第 4 欄標題文字跟 Level 1 不同，但順序一樣，這樣讀不受影響）
- 兩份都需要設定為「知道連結的任何人皆可查看」
- ⚠️ 因為是自動偵測，**沒有逐單元的啟用/停用開關**：只要 Sheet 裡有某個單元的資料，該單元就會出現在網站上。想先不開放某些單元，需要把該單元的資料列暫時搬出這兩份 Sheet，而不是靠開關控制。
- 新增 Unit 41 以後的單元：直接在對應 Level 的這兩份 Sheet 加資料、單元名稱一致即可，網站會自動抓到，不用改程式碼。

### 新增 Level 3 以後

1. 準備好該 Level 的單字清單、例句清單兩份 Sheet（格式比照 Level 1/2），設定為「知道連結的任何人皆可查看」
2. 到 [`js/config.js`](js/config.js) 新增兩個常數（例如 `ENGLISH_LEVEL3_VOCAB_SHEET_ID`、`ENGLISH_LEVEL3_SENTENCE_SHEET_ID`）
3. 到 [`js/englishdata.js`](js/englishdata.js) 的 `ENGLISH_LEVELS` 陣列多加一筆 `{ courseName: 'Level 3', vocabSheetId: ..., sentenceSheetId: ... }`

網站會自動多出「英文 > Level 3」課程與對應的老師編輯連結，不用再改其他地方。

## 錯題本（學生重新練習自己的錯題）

英文測驗（A/B 兩種類別）每次答錯的題目，會自動存進一份「錯題紀錄」Google Sheet，供學生登入後在首頁點「📕 我的錯題」重新練習：

| 項次 | 學生姓名 | 科目 | 課程 | 單元 | 題型 | 測驗時間 | 題目 | 正確答案 | 學生作答 | 選項 | 啟用與否 | 登載時間 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|

- 每答錯一題存一列；「選項」欄存當時的 4 個選項（用「｜」分隔），拼字題沒有選項所以留空，重測時如果是選擇題會用這欄還原成選擇題畫面
- **項次**、**登載時間**（伺服器收到當下的台灣時間）由 Apps Script 自動填入；**啟用與否**新增時自動填「是」
- 只有英文（A/B）的錯題會記錄，其他科目（目錄 Sheet 維護的舊架構）不記錄
- 重測答對後，這筆歷史紀錄**不會**消失（永久保留，方便老師事後統計哪些題目最多人錯）；同一題錯過幾次，畫面上只會列一次，但會顯示「已錯 N 次」
- 如果想讓某筆錯題不要再出現在學生的錯題本裡（但保留歷史資料），把 Sheet 裡那一列的「啟用與否」手動改成「否」即可，不用整列刪除
- 錯題本頁面依「單元 + 題型」分組，每組有自己的「重新測驗」按鈕；重測時会照原本的作答方式（選擇題／拼字題），測驗紀錄的題型會加註「（錯題重測）」以便和一般測驗區分

### 運作方式與部署步驟

跟「測驗紀錄」一樣，讀取用公開 CSV 網址直接抓，**寫入**需要透過部署在該 Sheet 上的 Apps Script。網站呼叫的端點網址設定在 [`js/quizlog.js`](js/quizlog.js) 的 `WRONG_LOG_ENDPOINT` 常數（`WRONG_LOG_ENDPOINT` 是空字串時代表尚未部署，錯題就不會被記錄，但不影響學生看到自己的測驗結果）。部署步驟跟測驗紀錄完全一樣：

1. 開啟「錯題紀錄」Google Sheet → 擴充功能 → Apps Script
2. 貼上 [`apps-script/wrong-log.gs`](apps-script/wrong-log.gs) 的內容並存檔
3. 部署 → 新增部署作業 → 網頁應用程式（執行身份：我；存取權：任何人）
4. 把部署後的網址（結尾 `/exec`）交給我，填入 `WRONG_LOG_ENDPOINT`

⚠️ 一樣要提醒：這組網址之後會出現在公開原始碼裡，沒有辦法完全防止有人送假資料進來；如果發現被濫用，可以重新部署一組新網址止血。

## 其他科目／單元 目錄（維護重點）

英文以外的科目、課程、單元，一樣可以用「目錄 Google Sheet」維護（跟原本的方式相同）：

- 目錄 Sheet ID 設定在 [`js/config.js`](js/config.js) 的 `DIRECTORY_SHEET_ID` 常數
- 目錄 Sheet 的欄位（依**順序**讀取，不是依標題文字，所以就算標題列被改動也不影響）：

  | 欄位順序 | 說明 |
  |---|---|
  | 1 | 科目名稱，例如「國文」「數學」「生物」「社會」 |
  | 2 | 課程名稱，例如「第1回」 |
  | 3 | 單元名稱，例如「單元04-數量詞」 |
  | 4 | 該單元題庫的 Google Sheet ID（該題庫網址中 `/d/` 與 `/edit` 之間那段） |
  | 5 | 啟用：填「是」才會顯示在網站上，其他（含空白）都視為未啟用 |

- **新增科目、課程、單元，都只要在這份目錄 Sheet 裡新增一列即可，不需要改程式碼、也不需要重新部署。**
- 網站只會顯示至少有一個「啟用」單元的科目／課程，避免出現空白頁面。
- ⚠️ **不要在這份目錄 Sheet 裡再列「英文」了**：英文已經改成自動偵測，如果目錄 Sheet 裡還留著「英文」的舊列，網站會自動合併，同名單元一律以自動偵測的新資料為準（不會出現重複或跑錯資料），但建議還是清掉舊列比較乾淨。
- 單元在網站上出現的順序，就是目錄 Sheet 由上到下的列順序。
- 目錄 Sheet 跟每份單元題庫一樣，都需要設定為「知道連結的任何人皆可查看」。

這類（非英文）單元題庫的 Google Sheet 需符合以下欄位（見任一份現有題庫）：

| 單元 | 題號 | 題目 | 正確答案 | 第一個其他答案 | 第二個其他答案 | 第三個其他答案 |
|---|---|---|---|---|---|---|

- `題目` 中的空格請用底線表示，例如 `Judy is _____ hard-working student.`
- 若某題的錯誤選項不足 3 個，可以用 `X` 填入空缺欄位，程式會自動忽略。
- 一樣需要設定為「知道連結的任何人皆可查看」。

## 更新 CSS / JS 後記得升版本號（避免瀏覽器快取舊版）

三個 HTML 檔（`index.html`、`quiz.html`、`wrongbook.html`）裡的 `css/style.css` 及 `js/*.js` 都加了 `?v=11` 這種版本號查詢字串。瀏覽器與 GitHub Pages 的 CDN 會用檔名（含查詢字串）快取檔案，如果修改了 CSS 或 JS 卻沒改版本號，使用者可能會看到舊版內容。

**每次修改 `css/` 或 `js/` 裡的檔案並要推上 GitHub 時，記得把三個 HTML 檔裡所有 `?v=N` 的數字都往上加一。**

如果使用者回報「怎麼改了都沒變」，通常就是這個快取問題，請他們對頁面按 `Ctrl+Shift+R`（強制重新整理）。

## 本機預覽

這是純靜態網站，用任何簡易 HTTP 伺服器開啟 `index.html` 即可（部分瀏覽器對 `file://` 開啟本地檔案會有限制，建議用本機伺服器）：

```bash
npx serve .
```

或使用 Python：

```bash
python -m http.server 8000
```

然後開啟 http://localhost:8000

## 部署到 GitHub Pages

1. 將此資料夾推送到 GitHub 上的一個 repository
2. 到 repository 的 **Settings → Pages**
3. Source 選擇 `Deploy from a branch`，Branch 選擇 `main`（或 `master`）、資料夾選擇 `/ (root)`
4. 儲存後，GitHub 會提供一個 `https://<你的帳號>.github.io/<repo名稱>/` 網址
